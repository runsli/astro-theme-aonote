## GitHub Discussions — Show and tell

**Title:** astro-theme-aonote — Astro port of the Aonote static blog theme

**Body:**

I ported [runsli/Aonote](https://github.com/runsli/Aonote) (Python static blog) to an Astro starter theme.

- Demo: https://astro-theme-aonote.vercel.app
- Repo: https://github.com/runsli/astro-theme-aonote
- Install: `npm create astro@latest -- --template runsli/astro-theme-aonote`

Features: GFM, MathML math, Shiki code blocks, admonitions, TOC, tags, archive, RSS/Atom, light/dark, zh-CN/en UI strings.

Feedback welcome in Issues.
